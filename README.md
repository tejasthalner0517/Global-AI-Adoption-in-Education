# Global AI Adoption in Education

## Project Overview
This project explores AI adoption in education using data analysis and interactive visualizations. It presents insights through a Tableau Dashboard and Tableau Story.

## Project Objectives
- Analyze AI adoption across countries and regions included in the dataset.
- Compare AI adoption by year, education level, user type, and AI tool.
- Explore AI usage hours and AI impact scores.
- Present findings through an interactive dashboard and story.

## Tools and Technologies
- Tableau Public
- Data analysis and visualization
- CSV dataset

## Dataset
The project uses a dataset containing information such as country, region, year, education level, user type, AI tool, AI adoption rate, usage hours, infrastructure score, impact score, and barriers.

**Note:** The dataset is sample/synthetic data and should not be treated as verified real-world global statistics.
